Thai Girls TOP9 Generator v11

Mobile-first update. The candidate initials/name overlay has been removed from the photo area so it never covers faces; names are displayed below each photo.

To play: unzip this folder and open index.html. For phone use, the most reliable method is to upload the folder to GitHub Pages or another static hosting service, then open the HTTPS page on the phone.

Put candidate photos in images/ using the filenames referenced by script.js.
